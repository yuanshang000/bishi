## 🔧 解决的问题

### 问题1: SQLAlchemy保留字冲突
**现象:** 模型中使用了`metadata`字段，与SQLAlchemy保留字冲突
**解决:** 将字段重命名为`doc_metadata`和`chat_metadata`

### 问题2: PyMySQL认证问题
**现象:** Alembic迁移时报"Access denied"错误
**原因:** .env文件中DATABASE_URL密码配置为空
**解决:** 将DATABASE_URL更新为正确的密码

### 问题3: SQLAlchemy 2.0语法更新
**现象:** `conn.execute("SELECT 1")`报错
**解决:** 使用`text()`包装原始SQL: `conn.execute(text("SELECT 1"))`

## 📝 使用说明

### 启动数据库连接

```python
from app.core.database import SessionLocal, get_db

# 方式1: 直接使用
db = SessionLocal()
try:
    # 执行数据库操作
    users = db.query(User).all()
finally:
    db.close()

# 方式2: FastAPI依赖注入
from fastapi import Depends

@app.get("/users")
def get_users(db: Session = Depends(get_db)):
    return db.query(User).all()
```
