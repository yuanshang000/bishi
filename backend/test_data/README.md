# 测试数据目录

本目录存放用于开发、测试和演示的示例数据文件。

## 📁 目录结构

```
test_data/
├── README.md       # 本说明文档
└── sample.txt      # 英语学习示例文本
```

## 📄 文件说明

### sample.txt - 英语学习示例文本

**用途：**
- 提供英语学习内容的示例数据
- 用于测试文档上传和向量化功能
- 演示系统如何处理英语学习材料

**内容：**
- 核心词汇（Core Vocabulary）
- 语法要点（Grammar Notes）
- 阅读段落（Reading Passage）
- 练习题目（Practice）

**使用场景：**
1. **测试文档上传**
   - 上传此文件测试文档处理流程
   - 验证文件解析功能

2. **测试向量化**
   - 测试文本向量化和 RAG 检索
   - 验证 Embedding 效果

3. **演示系统功能**
   - 作为演示数据展示系统功能
   - 快速验证系统是否正常工作

## 🔧 使用方法

### 通过 API 上传测试

```bash
# 上传示例文件
curl -X POST "http://localhost:8000/api/v1/documents/upload" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -F "file=@test_data/sample.txt" \
  -F "chapter_id=1"
```

### 通过前端上传测试

1. 登录系统
2. 进入章节管理
3. 上传 `sample.txt` 文件
4. 查看文档是否正确解析和向量化

## 📝 添加新测试数据

如需添加新的测试数据，请遵循以下规范：

1. **文件格式**
   - 支持格式：TXT、PDF、DOCX
   - 文件大小：不超过 50MB
   - 编码：UTF-8

2. **命名规范**
   - 使用有意义的文件名
   - 例如：`chapter1_vocabulary.txt`、`grammar_test.pdf`

3. **内容要求**
   - 内容应与英语学习相关
   - 结构清晰，便于解析
   - 包含标题、段落、练习等
