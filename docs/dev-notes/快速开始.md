# 快速开始指南

## 启动应用

### Windows

双击运行 `start.bat` 或在命令行执行：

```bash
.\start.bat
```

### Linux/Mac

```bash
chmod +x start.sh
./start.sh
```

或者手动启动：

```bash
# 激活虚拟环境
source venv/bin/activate

# 启动应用
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

## 访问API文档

启动后访问以下地址：

- **Swagger UI:** http://localhost:8000/docs
- **ReDoc:** http://localhost:8000/redoc
- **健康检查:** http://localhost:8000/health

## 首次使用

### 1. 注册用户

访问 http://localhost:8000/docs，找到 `POST /api/v1/auth/register` 接口：

```json
{
  "username": "teacher1",
  "password": "password123",
  "email": "teacher@example.com",
  "role": "teacher"
}
```

### 2. 登录获取令牌

使用 `POST /api/v1/auth/login` 登录：

```json
{
  "username": "teacher1",
  "password": "password123"
}
```

复制返回的 `access_token`。

### 3. 设置认证

在Swagger UI页面右上角点击 `Authorize` 按钮，输入：

```
Bearer <your_access_token>
```

### 4. 创建章节

使用 `POST /api/v1/chapters/` 创建第一个章节：

```json
{
  "chapter_number": 1,
  "title": "Unit 1: Campus Life",
  "description": "Introduction to campus life and daily routines",
  "learning_objectives": [
    "Learn vocabulary about campus life",
    "Practice describing daily routines"
  ],
  "key_points": [
    "Campus vocabulary",
    "Present simple tense",
    "Daily routine expressions"
  ]
}
```

### 5. 上传文档

使用 `POST /api/v1/documents/upload` 上传课程文档（PDF、DOCX或TXT）。

### 6. 向量化文档

使用 `POST /api/v1/documents/{id}/vectorize` 对上传的文档进行向量化处理。

### 7. 测试功能

- **创建练习:** `POST /api/v1/quiz/create`
- **聊天问答:** `POST /api/v1/chat/`

## 常见问题

### 1. 数据库连接失败

检查 `.env` 文件中的 `DATABASE_URL` 配置是否正确。

### 2. API密钥错误

确保在 `.env` 中配置了正确的 `DEEPSEEK_API_KEY` 和 `EMBEDDING_API_KEY`。

### 3. 文件上传失败

确保 `./uploads` 目录存在且有写入权限。

### 4. 向量化失败

检查：
- 文档内容是否为空
- Embedding API密钥是否正确
- ChromaDB目录 `./data/chroma` 是否可写

## 开发提示

日志文件位于 `./logs/app.log`

修改代码后，应用会自动重新加载（使用 `--reload` 参数）。

### 停止应用

按 `Ctrl+C` 停止服务器。
