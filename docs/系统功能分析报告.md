# 大学英语智慧助手 - 系统功能分析报告

> **项目概述：** 这是一个基于 FastAPI + Vue 3 + AI 的大学英语智能学习平台，实现分章节知识库、智能出题、自动评分、学情分析和薄弱点识别等核心功能。

---

## 一、项目技术架构

### 1.1 技术栈

**后端：**
- **框架：** FastAPI (Python 3.11+)
- **数据库：** MySQL 8.0+ (结构化数据) + ChromaDB (向量数据)
- **AI 核心：** 
  - LLM：DeepSeek/GPT-4o (通过 OpenAI API)
  - Embedding：DeepSeek Embedding API
  - RAG：LangChain + ChromaDB
- **其他：** SQLAlchemy (ORM), Pydantic (数据验证)

**前端：**
- **框架：** Vue 3 + TypeScript
- **UI 库：** Element Plus
- **状态管理：** Pinia
- **路由：** Vue Router
- **图表：** ECharts

**特色组件：**
- **MCP Server：** 独立 Python 进程，提供工具调用接口，连接数据库与 AI

#### 2.1.3 出题规则详解

**位置：** `出题规则.md`

**规则结构：**

1. **单词训练 (Vocabulary)**
   - 简单难度：听音默写、拼写检查、看英选义
   - 中等难度：词形变换、语境选词
   - 困难难度：熟词生义、无选项完形

2. **语法训练 (Grammar)**
   - 每个语法点生成 3 道题
   - 简单：形态填空、单项选择
   - 中等：改错题、时态辨析
   - 困难：句型转换、汉译英、语篇填空

3. **固定搭配 (Collocation)**
   - 每个短语至少 1 道题
   - 根据难度调整题型

4. **综合运用 (Synthesis)**
   - 仅在中/困难模式且同时包含单词、语法、短语时触发
   - 生成微型语篇 (150-200词)
   - 嵌入所有目标词汇和短语
   - 基于语篇生成 3-5 道题

#### 2.2.2 评分逻辑详解

**位置：** `backend/app/services/quiz_service.py` 的 `submit_quiz()` 方法

**核心评分方法：** `_check_answer()`

```python
@staticmethod
def _check_answer(
    user_answer,
    correct_answer,
    quiz_type,
    question,
    extra_info
) -> tuple[bool, float, str]:
    """
    评分方法
    
    Returns:
        (is_correct, score, feedback)
    """
    
    # 1. 选择题 - 精确匹配
    if quiz_type in ["choice", "vocabulary", "reading", "listening"]:
        if user_answer == correct_answer:
            return True, 100.0, "正确！"
        else:
            return False, 0.0, f"错误。正确答案是：{correct_answer}"
    
    # 2. 填空题 - 模糊匹配 (忽略大小写、空格)
    elif quiz_type == "blank":
        if user_answer and correct_answer:
            user_clean = user_answer.strip().lower()
            correct_clean = correct_answer.strip().lower()
            if user_clean == correct_clean:
                return True, 100.0, "正确！"
        
        # 部分匹配
        similarity = calculate_similarity(user_answer, correct_answer)
        if similarity >= 0.8:
            return False, 50.0, "部分正确，请检查拼写"
        else:
            return False, 0.0, "错误"
    
    # 3. 翻译题 - LLM 语义评估
    elif quiz_type == "translation":
        feedback = llm_service.evaluate_translation(
            question_text=question,
            user_answer=user_answer,
            correct_answer=correct_answer
        )
        # 从反馈中提取分数
        score = extract_score_from_feedback(feedback)
        is_correct = score >= 90.0
        return is_correct, score, feedback
    
    # 4. 写作题 - LLM 全面评估
    elif quiz_type == "writing":
        feedback = llm_service.evaluate_writing(
            topic=extra_info.get('topic', ''),
            requirements=extra_info.get('requirements', []),
            user_answer=user_answer,
            sample_answer=correct_answer
        )
        score = extract_score_from_feedback(feedback)
        is_correct = score >= 60.0
        return is_correct, score, feedback
```

#### 2.2.3 知识点统计更新 (智能分批)

**核心算法：**

```python
# 1. 识别题目对应的知识点
target_item = question.get('target_item')  # 如 "ambitious"

# 2. 查找 KnowledgePoint

    UserKnowledgePointStats.user_id == user_id,
    UserKnowledgePointStats.knowledge_point_id == kp.id
).first()

if not user_kp_stat:
    user_kp_stat = UserKnowledgePointStats(
        user_id=user_id,
        knowledge_point_id=kp.id,
        total_attempts=0,
        correct_attempts=0,
        consecutive_errors=0,
        consecutive_corrects=0,
        mastery_score=0.0
    )
    db.add(user_kp_stat)

# 4. 根据答题结果更新统计
if item_score >= 0.9:  # 做对
    user_kp_stat.total_attempts += 1
    user_kp_stat.correct_attempts += 1
    user_kp_stat.consecutive_errors = 0
    user_kp_stat.consecutive_corrects += 1
    user_kp_stat.mastery_score = min(100.0, user_kp_stat.mastery_score + 10.0)
    
elif item_score >= 0.4:  # 半对
    user_kp_stat.total_attempts += 1
    user_kp_stat.consecutive_errors = 0
    user_kp_stat.consecutive_corrects = 0
    user_kp_stat.mastery_score = max(0.0, user_kp_stat.mastery_score - 5.0)
    
else:  # 做错
    user_kp_stat.total_attempts += 1
    user_kp_stat.consecutive_errors += 1
    user_kp_stat.consecutive_corrects = 0
    user_kp_stat.mastery_score = max(0.0, user_kp_stat.mastery_score - 15.0)
```

**掌握度分数机制：**
- 做对一次：+10 分
- 做错一次：-15 分
- 半对：-5 分
- 范围：0-100 分

#### 2.3.2 核心代码实现

**位置：** `backend/app/services/ai_analysis_service.py` 的 `get_weak_points_detail()` 方法

**关键逻辑：**

```python
async def get_weak_points_detail(self, db: Session, student_id: int) -> List[Dict[str, Any]]:
    
    # 1. 计算小节 Quiz 平均分
    quiz_records = db.query(QuizRecord).filter(
        QuizRecord.user_id == student_id,
        QuizRecord.is_completed == 1,
        QuizRecord.subsection_id.isnot(None)
    ).all()
    
    subsection_quiz_stats = {}
    for qr in quiz_records:
        sid = qr.subsection_id
        if sid not in subsection_quiz_stats:
            subsection_quiz_stats[sid] = {"total_acc": 0, "count": 0}
        subsection_quiz_stats[sid]["total_acc"] += (qr.accuracy or 0)
        subsection_quiz_stats[sid]["count"] += 1
    
    # 2. 获取知识点精准统计
    stats_query = db.query(UserKnowledgePointStats, KnowledgePoint).join(
        KnowledgePoint, UserKnowledgePointStats.knowledge_point_id == KnowledgePoint.id
    ).filter(
        UserKnowledgePointStats.user_id == student_id,
        UserKnowledgePointStats.total_attempts > 0
    ).all()
    
    # 3. 按小节聚合
    subsection_map = {}
    for u_stat, kp in stats_query:
        sid = kp.subsection_id
        if sid not in subsection_map:
            subsection_map[sid] = {
                "total_attempts": 0,
                "correct_attempts": 0,
                "kp_list": []
            }
        subsection_map[sid]["total_attempts"] += u_stat.total_attempts
        subsection_map[sid]["correct_attempts"] += u_stat.correct_attempts
        subsection_map[sid]["kp_list"].append((u_stat, kp))
    
    # 4. 分析每个不及格小节
    for sid, data in subsection_map.items():
        # 优先使用 QuizRecord 数据
        if sid in subsection_quiz_stats:
            avg_accuracy = subsection_quiz_stats[sid]["total_acc"] / subsection_quiz_stats[sid]["count"]
        else:
            avg_accuracy = (data["correct_attempts"] / data["total_attempts"]) * 100
        
        # 只显示不及格的小节
        if avg_accuracy >= 60:
            continue
        
        # 提取薄弱知识点
        sub_weak_points = []
        for u_stat, kp in data["kp_list"]:
            kp_acc = u_stat.correct_attempts / u_stat.total_attempts
            
            # 只添加正确率 < 60% 的知识点
            if kp_acc < 0.6:
                sub_weak_points.append({
                    "knowledge_point_id": kp.content,
                    "type": type_map.get(kp.type, kp.type),
                    "error_count": u_stat.total_attempts - u_stat.correct_attempts,
                    "accuracy": round(kp_acc * 100, 1),
                    "total_attempts": u_stat.total_attempts
                })
        
        # 如果没有严格薄弱点，显示最差的几个
        if not sub_weak_points:
            sub_weak_points = sorted(sub_weak_points, key=lambda x: x['accuracy'])[:5]
        
        # 生成建议
        suggestion = "建议加强练习"
        types = set(wp['type'] for wp in sub_weak_points)
        if '单词' in types:
            suggestion += "，重点记忆单词拼写和词义"
        if '语法' in types:
            suggestion += "，复习相关语法规则和例句"
        
        results.append({
            "knowledge_point_id": f"第{chapter_num}章 - {subsection.title}",
            "average_score": round(avg_accuracy, 1),
            "severity": "high",
            "severity_text": "未达标",
            "weak_details": sub_weak_points[:5],
            "suggestion": suggestion
        })
    
    return results
```

#### 2.3.3 数据模型

**UserKnowledgePointStats 表：**
```sql
CREATE TABLE user_knowledge_point_stats (
    id INT PRIMARY KEY AUTO_INCREMENT,
    user_id INT NOT NULL,
    knowledge_point_id INT NOT NULL,
    total_attempts INT DEFAULT 0,        -- 总尝试次数
    correct_attempts INT DEFAULT 0,      -- 正确次数
    consecutive_errors INT DEFAULT 0,    -- 连续错误次数
    consecutive_corrects INT DEFAULT 0,  -- 连续正确次数
    mastery_score FLOAT DEFAULT 0.0,     -- 掌握度分数 (0-100)
    last_reviewed_at DATETIME,
    FOREIGN KEY (user_id) REFERENCES users(id),
    FOREIGN KEY (knowledge_point_id) REFERENCES knowledge_points(id)
);
```

**KnowledgePoint 表：**
```sql
CREATE TABLE knowledge_points (
    id INT PRIMARY KEY AUTO_INCREMENT,
    subsection_id INT NOT NULL,
    content VARCHAR(255) NOT NULL,       -- 知识点内容 (单词/短语/语法点)
```

```python
def vectorize_document(self, db: Session, document_id: int) -> bool:
    # 1. 获取文档
    doc = db.query(CourseDocument).filter(
        CourseDocument.id == document_id
    ).first()

    cleaned_content = clean_document_properties(doc.content)

    embeddings = self.get_embeddings(chunks)

            "chapter_id": int(doc.chapter_id),
            "doc_type": str(doc.doc_type.value),
            "title": str(doc.title),
            "chunk_index": int(i),
        }
        for i in range(len(chunks))

    # 6. 批量添加到 ChromaDB

        ids=chunk_ids,

        documents=chunks,
        metadatas=metadatas
    )

    doc.is_vectorized = 1
    doc.vector_count = len(chunks)
```

```python
def get_context_for_query(
    self,
    query: str,
    chapter_id: Optional[int] = None,
    max_length: int = 2000
) -> tuple[str, List[Dict], List[Dict]]:
    
    # 1. 生成查询向量
    query_embedding = self.get_embeddings([query])[0]
    
    # 2. 构建过滤条件
    where = {}
    if chapter_id is not None:
        where["chapter_id"] = int(chapter_id)
    
    # 3. 检索
    results = self.collection.query(
        query_embeddings=[query_embedding],
        n_results=5,
        where=where if where else None,
        include=["documents", "metadatas", "distances"]
    )
    
    # 4. 格式化结果
    context_parts = []
    used_documents = []
    used_chunks = []
    current_length = 0
    
    for i, doc in enumerate(results['documents'][0]):
        metadata = results['metadatas'][0][i]
        score = 1 - results['distances'][0][i]
        
        # 添加标题前缀
        title_prefix = f"【{metadata.get('doc_type', '文档')}: {metadata.get('title')}】\n"
        full_content = title_prefix + doc
        
        if current_length + len(full_content) > max_length:
            break
        
        context_parts.append(full_content)
        current_length += len(full_content)
        
        # 收集文档信息
        used_chunks.append({
            "index": i,
            "preview": doc[:200] + "...",
            "score": score,
            **metadata
        })
    
    context = "\n\n---\n\n".join(context_parts)
    return context, used_documents, used_chunks
```

```python
def chat_with_tools(
    self,
    db: Session,
    messages: List[Dict[str, Any]],
    student_id: Optional[int] = None,
    **kwargs
) -> str:
    
    # 1. 第一次调用 LLM
    response = self.client.chat.completions.create(
        model=self.model,
        messages=messages,
        tools=TOOL_DEFINITIONS,
        tool_choice="auto"
    )
    
    tool_calls = response.choices[0].message.tool_calls
    
    if tool_calls:
        # 2. 执行工具调用
        for tool_call in tool_calls:
            function_name = tool_call.function.name
            function_args = json.loads(tool_call.function.arguments)
            
            # 自动注入 student_id
            if student_id is not None and "student_id" not in function_args:
                function_args["student_id"] = student_id
            
            # 调用对应的工具函数
            if function_name == "get_student_weak_points":
                function_response = get_student_weak_points(
                    db=db,
                    **function_args
                )
            elif function_name == "generate_interactive_quiz":
                function_response = generate_interactive_quiz(
                    db=db,
                    **function_args
                )
            # ... 其他工具
            
            # 将工具结果添加到消息历史
            messages.append({
                "tool_call_id": tool_call.id,
                "role": "tool",
                "name": function_name,
                "content": json.dumps(function_response, ensure_ascii=False)
            })
        
        # 3. 第二次调用 LLM，生成最终回答
        second_response = self.client.chat.completions.create(
            model=self.model,
            messages=messages
        )
        
        return second_response.choices[0].message.content
    
    return response.choices[0].message.content
```

   - 进入 AI 学情分析
   - 查看薄弱知识点列表
   - 查看针对性建议

3. **针对性训练**
   - 点击薄弱点进行强化练习
   - 系统生成变式题
   - 直到掌握度达标

4. **智能问答**
   - 提问具体知识点
   - AI 回答并溯源章节
   - 自动生成练习题巩固

## 七、技术难点与解决方案

### 7.1 难点1：题目格式一致性

**问题：** LLM 生成的题目格式可能不一致

**解决方案：**
- 严格的 JSON Schema 定义
- 多次重试机制
- 后处理验证和修正

### 7.2 难点2：知识点识别准确性

**问题：** 如何准确识别题目对应的知识点

**解决方案：**
- 使用 `target_item` 字段显式标注
- 支持多种匹配策略（精确、前缀、包含）
- 优先在当前小节内查找

### 7.3 难点3：向量检索相关性

**问题：** 检索到的内容可能不相关

**解决方案：**
- 智能分块策略（保持语义完整）
- 多种检索策略（章节级、小节级）
- 混合检索（精确 + 语义）

### 7.4 难点4：LLM 评分一致性

**问题：** 翻译题和写作题评分主观性强

**解决方案：**
- 设计详细的评分标准
- 使用 Chain of Thought 提示
- 结合参考答案进行对比
