## 💡 配置说明

### 后端配置 (.env)

```bash
# 数据库
DATABASE_URL=mysql+pymysql://root:your_password@localhost:3306/college_english_assistant

# JWT
SECRET_KEY=your-secret-key-change-this-in-production

# LLM API
DEEPSEEK_API_KEY=sk-your-api-key
EMBEDDING_API_KEY=sk-your-api-key
```

### 前端配置 (vite.config.ts)

```typescript
server: {
  port: 5173,
  proxy: {
    '/api': {
      target: 'http://localhost:8000',
      changeOrigin: true
    }
  }
}
```
