# 大学英语智慧助手 - 项目启动指南

## 一、环境要求

### 1.1 必需软件
- **Python**: 3.11.x 或更高版本
- **Node.js**: 16.x 或更高版本（推荐使用 LTS 版本）
- **MySQL**: 8.0 或更高版本
- **Git**: 用于克隆项目

### 1.2 检查环境
```bash
# 检查 Python 版本
python --version

# 检查 Node.js 版本
node --version

# 检查 npm 版本
npm --version

# 检查 MySQL 是否运行
# 在命令行输入：mysql -u root -p
```

## 二、数据库配置

### 2.1 创建数据库
```bash
# 登录 MySQL
mysql -u root -p

# 创建数据库
CREATE DATABASE college_english_assistant CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

## 三、后端配置和启动

### 3.1 进入后端目录
```bash
cd backend
```

### 3.2 创建虚拟环境（推荐）
```bash
# 创建虚拟环境
python -m venv venv

# 激活虚拟环境
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate
```

### 3.3 安装依赖
```bash
pip install -r requirements.txt
```

如果安装速度慢，可以使用国内镜像源：
```bash
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 3.4 配置环境变量
1. 复制环境变量模板：
```bash
copy .env.example .env
```

2. 编辑 `.env` 文件，修改以下配置：

```env
# 应用配置
APP_NAME="College English Assistant"
APP_ENV=development
DEBUG=True

# 服务器配置
HOST=0.0.0.0
PORT=8000

# 数据库配置（重要：修改为你的实际配置）
DATABASE_URL=mysql+pymysql://root:你的密码@localhost:3306/college_english_assistant
DB_POOL_SIZE=20
DB_MAX_OVERFLOW=10

# JWT配置
SECRET_KEY=college-english-assistant-secret-key-2024
ALGORITHM=HS256
ACCESS_TOKEN_EXPIRE_MINUTES=1440

# LLM API配置（重要：配置你的AI服务）
# 所有API请求都统一使用LLM_BASE_URL，无需在代码中额外设置

# 示例1：使用第三方API（如DS2API）
LLM_PROVIDER=openai
OPENAI_API_KEY=你的第三方API密钥
LLM_BASE_URL=http://127.0.0.1:5001/v1
LLM_MODEL=deepseek-chat
LLM_TIMEOUT=30

# 示例2：使用OpenAI官方API
# LLM_PROVIDER=openai
# OPENAI_API_KEY=sk-your-openai-api-key-here
# LLM_BASE_URL=https://api.openai.com/v1
# LM_MODEL=gpt-3.5-turbo
# LLM_TIMEOUT=30

# 示例3：使用DeepSeek官方API
# LLM_PROVIDER=deepseek
# DEEPSEEK_API_KEY=sk-your-deepseek-api-key-here
# LLM_BASE_URL=https://api.deepseek.com/v1
# LLM_MODEL=deepseek-chat
# LLM_TIMEOUT=30

# Embedding API配置
EMBEDDING_PROVIDER=openai
EMBEDDING_API_KEY=你的API密钥
EMBEDDING_BASE_URL=http://127.0.0.1:5001/v1
EMBEDDING_MODEL=text-embedding-ada-002
EMBEDDING_DIMENSION=1536

# ChromaDB配置
CHROMA_PERSIST_DIR=./data/chroma
CHROMA_COLLECTION_NAME=course_embeddings

# 文件上传配置
UPLOAD_DIR=./uploads
MAX_FILE_SIZE=52428800

# 日志配置
LOG_LEVEL=INFO
LOG_DIR=./logs

# CORS配置
CORS_ORIGINS=["http://localhost:3000","http://localhost:5173","http://localhost:8080"]
```

### 3.5 启动后端服务
#### 方法一：使用创建的启动脚本（推荐）
```bash
start_fixed.bat
```

#### 方法二：手动启动
```bash
# Windows CMD
set PORT=8000 && python -m app.main

# Windows PowerShell
$env:PORT=8000; python -m app.main

# 或者直接运行（如果环境变量没有冲突）
python -m app.main
```

### 3.6 验证后端启动
打开浏览器访问：
- http://localhost:8000 - 应该看到欢迎信息
- http://localhost:8000/docs - API 文档界面

## 四、前端配置和启动

### 4.1 进入前端目录
```bash
cd frontend
```

### 4.2 安装依赖
```bash
npm install
```

如果安装速度慢，可以使用国内镜像源：
```bash
npm install --registry=https://registry.npmmirror.com
```

### 4.3 配置代理（已配置，无需修改）
前端已经配置了代理，会自动将 `/api` 请求转发到 `http://localhost:8000`。

配置文件在 `vite.config.ts`：
```typescript
server: {
  port: 5173,
  proxy: {
    '/api': {
      target: 'http://localhost:8000',
      changeOrigin: true
    },
    '/static': {
      target: 'http://localhost:8000',
      changeOrigin: true
    }
  }
}
```

### 4.4 启动前端服务
```bash
npm run dev
```

或者使用启动脚本：
```bash
start.bat
```

### 4.5 验证前端启动
打开浏览器访问：
- http://localhost:5173 - 应该看到应用界面

## 五、常见问题解决

### 5.1 端口被占用
**问题**：启动时提示端口 8000 或 5173 已被占用

**解决方案**：
```bash
# 查找占用端口的进程
netstat -ano | findstr ":8000"

# 结束进程（使用上一步找到的 PID）
taskkill /PID <进程ID> /F
```

### 5.2 数据库连接失败
**问题**：无法连接到 MySQL 数据库

**解决方案**：
1. 检查 MySQL 服务是否启动
2. 确认 `.env` 文件中的数据库配置正确
3. 确认数据库已创建：`CREATE DATABASE college_english_assistant;`
4. 确认用户名和密码正确

### 5.3 依赖安装失败
**问题**：pip 或 npm install 失败

**解决方案**：
```bash
# Python 依赖 - 使用国内镜像源
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

# Node 依赖 - 使用国内镜像源
npm install --registry=https://registry.npmmirror.com

# 清理缓存后重试
pip cache purge
npm cache clean --force
```

### 5.4 后端端口不正确
**问题**：后端启动时使用了错误的端口（如 63157 而不是 8000）

**解决方案**：
使用创建的 `start_fixed.bat` 脚本启动，或在启动前设置环境变量：
```bash
set PORT=8000 && python -m app.main
```

### 5.5 前端无法连接后端
**问题**：前端页面显示"服务器内部错误"

**解决方案**：
1. 确认后端服务在 8000 端口正常运行
2. 检查 `vite.config.ts` 中的代理配置是否正确
3. 查看浏览器控制台的错误信息
4. 查看后端日志文件：`backend/backend_error.txt`

### 5.6 CORS 错误
**问题**：浏览器控制台显示 CORS 错误

**解决方案**：
确认 `.env` 文件中的 CORS 配置包含前端地址：
```env
CORS_ORIGINS=["http://localhost:5173"]
```

### 5.7 API 密钥错误
**问题**：AI 功能无法使用，显示 API 错误

**解决方案**：
1. 确认 `.env` 文件中的 API 密钥配置正确
2. 确认 API 服务地址可以访问
3. 检查 API 密钥是否有效

## 六、快速启动脚本

### 一键启动后端和前端

**Windows** 创建 `start_all.bat`：
```batch
@echo off
echo Starting backend...
start cmd /k "cd backend && set PORT=8000 && python -m app.main"

timeout /t 5 /nobreak

echo Starting frontend...
start cmd /k "cd frontend && npm run dev"

echo Services started!
echo Backend: http://localhost:8000
echo Frontend: http://localhost:5173
```

使用方法：
```bash
start_all.bat
```

## 十一、注意事项

1. **端口冲突**：确保 8000 和 5173 端口没有被其他程序占用
2. **数据库**：确保 MySQL 服务正在运行，数据库已创建

4. **环境变量**：确保 `.env` 文件配置正确
5. **依赖安装**：确保所有依赖都已正确安装
6. **防火墙**：确保防火墙允许相关端口的访问
